When you stop speaking (VAD), your line is transcribed (ASR) and the extractor reads ONLY your words plus the machine state and answers set / yes / no / cancel with the values you said. The machine (gateway) merges them, decides what is missing, queries the database and updates the screen. yes is the only event that writes: it books, or cancels an existing booking after the screen asks CANCEL IT?. At the end of each model turn, σ (a cloud LLM) reports readbacks and claims; a claim the database contradicts turns the banner red with a spoken correction; if the model is stuck, σ writes the sentence to say on the banner and the controller opens its turn (force_speak). A turn that drags on is cut (force_listen).
