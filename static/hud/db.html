IDLE → COLLECTING (manca qualcosa) → RESULT; cancel → IDLE. Il campo "ultima battuta" è la trascrizione ASR grezza: qui si controlla la precisione delle date.

Inserisci una prenotazione

Date e ore vengono normalizzate come le estrae il tool agent ("March 31st" → march 31, "3 pm" → 15:00), così la verifica dell'HUD le ritrova.
